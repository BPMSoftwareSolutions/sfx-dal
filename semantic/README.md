# SFX.Semantics

The first read slice of the [Semantic Object Projection strategy](../docs/semantic-object-projection-strategy.md).
An installed SideFX reader is read in document mode, projected by CodeLightly into an immutable
C# snapshot, and verified against the live estate without changing it.

```text
contracts/                       maintained   semantic-projection.v1 contract (non-authoritative draft)
semantic-projection.config.json  maintained   which contracts to generate, namespace and output
SFX.Semantics/Generated/         generated    CodeLightly output and its manifest; regenerate, never edit
SFX.Semantics/SemanticReadClient.cs  maintained   snapshot-isolated, rolled-back read client
SFX.Semantics.Cli/               maintained   read / inspect / verify tool (assembly sfx-semantics)
regenerate.ps1                   maintained   offline, deterministic regeneration
```

The root `SFX.DAL` project excludes this tree (see [Directory.Build.props](../Directory.Build.props)).
Nothing here depends on the generated estate DAL.

## What the slice does

`CapabilitySnapshot` is generated from
[capability-details.semantic-projection.v1.json](contracts/capability-details.semantic-projection.v1.json).
It reads `analysis.read_capability_details` with `emit` bound to the constant `false`,
`capability_version_pk` omitted (never sent, so the procedure default applies) and the estate
pin bound explicitly.

- **Typed:** `capability_summary` (root), `scenarios`, `contracts`, `execution_operations`, `ports`,
  `bindings` and `providers`. Fields are typed from the October 9 row-mode metadata. A field is
  required only when that metadata is NOT NULL or the reader's `ROW` discriminator depends on it.
- **Retained:** the other 38 expected sections, marker rows (`EMPTY`, `SUMMARY`), undeclared
  fields and any row that cannot be typed. Each keeps its exact source text, so
  `ReconstructSourceDocument()` rebuilds a document semantically equal to the source.
- **Identity and provenance:** `Identity` is (namespace, kind, declared id, selected definition
  locator); the locator is database-scoped. `Provenance` records each bound argument, the reader
  definition digest, the document SHA-256, the isolation level and the read transaction's own
  estate log-record count.
- **References:** exact-key joins (`ResolveScenario`, `ResolvePort`, `ResolveProvider`) return
  `Resolved`, `Dangling` or `NotApplicable`. Nothing is ever fetched implicitly.
- **Digest:** `ProjectionDigest` hashes the canonical payload: RFC 8785 ordering, integers as
  strings, and opaque fragments bound by source-text SHA-256. Capture time and generator are
  excluded.
- **Availability:** `Present`, `Absent` (a declared reader refusal such as `CAPABILITY_NOT_FOUND`)
  or `ContractMismatch` (any error diagnostic). Availability says nothing about admission,
  conformance or mutation eligibility.

## Commands

Reads use the `sidefx-connection-string` Machine setting and never print it.

```powershell
# Offline regeneration: generates twice, compares bytes, checks drift, builds semantic/ and SFX.DAL.
./semantic/regenerate.ps1 -CodeLightlyRoot C:\source\repos\bpm\intelligence\03-engineering-intelligence\Codelightly `
  -ReceiptPath verification/semantic-generation-new.json

# Live read; prints the bounded inspection view. --save-source keeps the full document: keep it out of the repo.
dotnet run --project semantic/SFX.Semantics.Cli -c Release -- read ui-page-landing

# Offline projection of a saved read.
dotnet run --project semantic/SFX.Semantics.Cli -c Release -- inspect --source <saved.json>

# The 14 acceptance checks against the live estate, with a payload-free receipt.
dotnet run --project semantic/SFX.Semantics.Cli -c Release -- verify --receipt verification/semantic-slice-new.json
```

## Limits

The contract is a reviewed draft held here. It becomes a runtime contract only once an
estate-owned declaration is exported to replace it. One capability has been verified so far.
Provider and graph roots, a positive canonical graph, Python/Java emitters, the hosted endpoint
and every mutation remain later gates in the strategy. The current output was generated by
CodeLightly `8363c09`; the manifest records `+uncommitted` whenever generator source is dirty.
